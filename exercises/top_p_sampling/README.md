# 推理第 7 课：Top-p——怎样构造采样候选集？

## 概念

Top-p（nucleus）过滤会先考虑概率最高的 token，并按概率从高到低累计，取出让累计概率第一次达到 `p` 的**最小前缀**。达到阈值的那个 token 也要完整保留，不能只保留它的一部分概率。

随后把保留下来的概率重新归一化，使它们的总和为 1。过滤后的集合才是采样候选集。

```text
按概率降序排列 → 选最小累计前缀 → 重新归一化 → 从候选集中采样
```

本题只实现过滤和归一化，不执行随机采样。

## 输入与输出

在 `solution.py` 中实现：

```python
def top_p_filter(
    probabilities: list[float],
    p: float,
) -> list[tuple[int, float]]:
    ...
```

- `probabilities[i]`：token `i` 的概率。输入非空、概率非负且总和为 1。
- `p`：累计概率阈值，范围为 `(0, 1]`。
- 返回 `(token_id, 新概率)`，顺序仍为概率降序。
- 概率相同时按 token ID 升序排列。这是本练习为了确定测试结果额外约定的规则；真实 PyTorch `torch.sort` 未显式保证平频顺序。
- 选择累计概率大于等于 `p` 的最小前缀，并用该前缀的概率总和重新归一化。
- 不要修改输入的 `probabilities` 列表。

## 手算示例

```python
probabilities = [0.1, 0.5, 0.3, 0.1]
p = 0.7
```

按“概率降序、平频 ID 升序”排列：

```text
(token 1, 0.5) → 累计 0.5，小于 0.7，继续
(token 2, 0.3) → 累计 0.8，达到 0.7，停止
```

候选集保留 token 1 和 token 2，概率总和为 `0.8`。重新归一化：

```text
token 1：0.5 / 0.8 = 0.625
token 2：0.3 / 0.8 = 0.375
```

输出：

```python
[(1, 0.625), (2, 0.375)]
```

### 平频示例

```python
top_p_filter([0.25, 0.25, 0.25, 0.25], 0.5)
```

前两个 token 的累计概率恰好为 `0.5`，平频时先选较小 ID，因此输出：

```python
[(0, 0.5), (1, 0.5)]
```

当 `p = 1` 且所有 token 的概率都大于 0 时，累计前缀必须覆盖整个分布，所以所有 token 都会被保留；重新归一化后概率不变。如果分布末尾有零概率 token，按照“最小前缀”规则可以在累计概率达到 1 时停止，无需保留这些零概率尾部。

## 过滤之后还要采样

Top-p 不是“选当前最大概率 token”。例如上面的结果不能总是返回 token 1，而应按 `0.625` 和 `0.375` 的相对概率随机抽取。贪心解码是另一种策略；top-p 采样保留了多个可能性，同时排除了累计分布尾部的低概率候选。
